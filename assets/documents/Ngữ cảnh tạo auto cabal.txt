🧩 Ngữ cảnh dự án: Auto Game Cabal Origin bằng Python (Cập nhật 2025-10-18, Sprint 8 Complete - Enhanced Logging System)

🎯 Mục tiêu
- Auto thao tác an toàn cho Cabal VTC Origin: ưu tiên gửi phím (không cần click), mở rộng nhận diện ảnh đa mẫu.
- Cung cấp GUI Hunt ổn định: chọn đúng cửa sổ game theo PID/HWND, đưa lên trước, thu nhỏ GUI để phím vào game, có hotkey dừng toàn cục.
- Thiết kế lại quản lý quái/thư viện ảnh: CRUD tách riêng, hỗ trợ nhiều template 2D mỗi quái và lưu vùng cửa sổ.

- Thư mục project: E:\Cabal_Auto
- Python: 3.14.0 (venv tại `E:\Cabal_Auto\venv`)
- Trình chạy: PowerShell (khuyến nghị Start VS Code/PowerShell As Administrator để global hotkey đáng tin cậy hơn)

📦 Thư viện trong venv

	{
		"click": { "x": 500, "y": 400, "interval_sec": 2.0 },
		"hotkeys": { "toggle": "f8", "exit": "f9" },
		"safety": { "failsafe": true, "pause_key": "f7" }
	}

- hunt_config.json (Hunt trong GUI hoặc CLI)
	Các khóa điển hình: 
	- window_title: chuỗi cần có trong tên cửa sổ (ví dụ "CABAL")
	- window_pid (tùy chọn) và/hoặc window_hwnd (tùy chọn): ưu tiên focus chính xác
	- target_key: phím chuyển mục tiêu (thường "TAB")
	- attack_keys: mảng phím tấn công, ví dụ ["1", "2", "3"]
	- attack_press_ms: thời gian nhấn mỗi phím (ms)
	- target_cycle_delay: độ trễ giữa các lần nhấn target_key khi đang tìm (s)
	- search_interval, attack_interval: chu kỳ quét ảnh/đánh (s)
	- lost_timeout_sec: thời gian mất dấu mục tiêu trước khi quay lại tìm (s)
	- template_path: đường dẫn ảnh template (tạm dùng trước khi hoàn tất thư viện template đa ảnh)
	- region: [left, top, width, height] để giới hạn tìm kiếm (sẽ chuyển sang cơ chế mặc định theo biên cửa sổ)
	- confidence, grayscale: tham số cho OpenCV nếu có
	- window_bounds (định hướng mới): {left, top, width, height} lưu biên cửa sổ game để mặc định vùng tìm kiếm
	- bring_to_front_each_cycle: true/false, có đưa game lên trước mỗi vòng hay không

🧠 Hành vi Hunt thông minh (state machine)
- Chế độ tìm (search): chỉ gửi target_key theo nhịp target_cycle_delay cho đến khi ảnh template xuất hiện trong region.
- Khi phát hiện mục tiêu: chuyển sang chế độ đánh (attack), lặp các attack_keys với attack_interval.
- Nếu mất ảnh mục tiêu liên tục quá lost_timeout_sec: quay lại chế độ tìm, tránh đổi mục tiêu quá sớm.
- Có thể cấu hình đưa cửa sổ game lên trước mỗi vòng để tăng độ tin cậy nhập phím.

🧪 Chuẩn bị template và region
- Thư viện ảnh mới: mỗi quái lưu nhiều template (góc/camera khác nhau) với ngưỡng confidence riêng (~0.8).
- Template được quản lý trong `monster_templates/` (định hướng) và liên kết trực tiếp với quái trong `monsters.json`.
- Mặc định vùng tìm là toàn bộ cửa sổ game (lưu `window_bounds`); vẫn cho phép đặt region tùy quái để tối ưu tốc độ.
- Nếu dùng Python 3.10/3.11 + opencv-python: có thể đặt confidence/grayscale để nhận diện chắc hơn; hiện tại fallback pyautogui.

📑 Schema monsters.json (cập nhật 2025-10-18)
- Trường chính trên mỗi quái:
	- id (tùy chọn), name, description (tùy chọn)
	- window_bounds: { left, top, width, height } — biên cửa sổ game mặc định để tìm ảnh
	- templates: danh sách các mẫu ảnh, mỗi phần tử gồm:
		- name: tên mẫu (tùy chọn)
		- path: đường dẫn ảnh (ưu tiên tương đối trong dự án)
		- threshold: ngưỡng khớp (0..1), mặc định gợi ý ~0.80–0.90
		- region_strategy: "window" | "custom" (mặc định dùng biên cửa sổ; custom dùng region riêng)
		- region: [left, top, width, height] — chỉ có khi region_strategy = "custom"
		- grayscale (tùy chọn): true/false khi dùng OpenCV
- Tương thích ngược: nếu còn trường đơn `template_path` ở nơi khác, runtime sẽ lấy template đầu tiên trong `templates[]` làm mặc định khi cần.
- Ví dụ rút gọn:
	{
		"name": "Coc go~",
		"description": "Quái rừng mở đầu",
		"window_bounds": { "left": 100, "top": 100, "width": 1280, "height": 720 },
		"templates": [
			{
				"name": "goc-45",
				"path": "assets/images/monsters/coc-45.png",
				"threshold": 0.85,
				"region_strategy": "window"
			},
			{
				"name": "zoom-gan",
				"path": "assets/images/monsters/coc-zoom.png",
				"threshold": 0.9,
				"region_strategy": "custom",
				"region": [200, 150, 600, 300]
			}
		]
	}

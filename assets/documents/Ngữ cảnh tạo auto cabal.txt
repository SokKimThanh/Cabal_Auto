🎯 Mục tiêu
- Auto thao tác an toàn cho Cabal VTC Origin: ưu tiên gửi phím (không cần click), mở rộng nhận diện ảnh đa mẫu.
- Cung cấp GUI Hunt ổn định: chọn đúng cửa sổ game theo PID/HWND, đưa lên trước, thu nhỏ GUI để phím vào game, có hotkey dừng toàn cục.

- 🎨 Progressive Disclosure: 3 UI modes (Beginner/Intermediate/Advanced) để giảm độ phức tạp.

⚙️ Cấu hình chính
- config.json (clicker cơ bản)
	{
		"click": { "x": 500, "y": 400, "interval_sec": 2.0 },
		"hotkeys": { "toggle": "f8", "exit": "f9" },
		"safety": { "failsafe": true, "pause_key": "f7" }
	}

- hunt_config.json (Hunt trong GUI hoặc CLI)
	Các khóa điển hình: 
	- window_title: chuỗi cần có trong tên cửa sổ (ví dụ "CABAL")
	- window_pid (tùy chọn) và/hoặc window_hwnd (tùy chọn): ưu tiên focus chính xác
	- target_key: phím chuyển mục tiêu (thường "TAB")
	- attack_keys: mảng phím tấn công, ví dụ ["1", "2", "3"]
	- attack_press_ms: thời gian nhấn mỗi phím (ms)
	- target_cycle_delay: độ trễ giữa các lần nhấn target_key khi đang tìm (s)
	- search_interval, attack_interval: chu kỳ quét ảnh/đánh (s)
	- lost_timeout_sec: thời gian mất dấu mục tiêu trước khi quay lại tìm (s)
	- template_path: đường dẫn ảnh template (tạm dùng trước khi hoàn tất thư viện template đa ảnh)
	- region: [left, top, width, height] để giới hạn tìm kiếm (sẽ chuyển sang cơ chế mặc định theo biên cửa sổ)
	- confidence, grayscale: tham số cho OpenCV nếu có
	- window_bounds (định hướng mới): {left, top, width, height} lưu biên cửa sổ game để mặc định vùng tìm kiếm
	- bring_to_front_each_cycle: true/false, có đưa game lên trước mỗi vòng hay không

🧪 Chuẩn bị template và region
- Thư viện ảnh mới: mỗi quái lưu nhiều template (góc/camera khác nhau) với ngưỡng confidence riêng (~0.8).
- Template được quản lý trong `monster_templates/` (định hướng) và liên kết trực tiếp với quái trong `monsters.json`.
- Mặc định vùng tìm là toàn bộ cửa sổ game (lưu `window_bounds`); vẫn cho phép đặt region tùy quái để tối ưu tốc độ.
- Nếu dùng Python 3.10/3.11 + opencv-python: có thể đặt confidence/grayscale để nhận diện chắc hơn; hiện tại fallback pyautogui.

📑 Schema monsters.json (cập nhật 2025-10-18)
- Trường chính trên mỗi quái:
	- id (tùy chọn), name, description (tùy chọn)
	- window_bounds: { left, top, width, height } — biên cửa sổ game mặc định để tìm ảnh
	- templates: danh sách các mẫu ảnh, mỗi phần tử gồm:
		- name: tên mẫu (tùy chọn)
		- path: đường dẫn ảnh (ưu tiên tương đối trong dự án)
		- threshold: ngưỡng khớp (0..1), mặc định gợi ý ~0.80–0.90
		- region_strategy: "window" | "custom" (mặc định dùng biên cửa sổ; custom dùng region riêng)
		- region: [left, top, width, height] — chỉ có khi region_strategy = "custom"
		- grayscale (tùy chọn): true/false khi dùng OpenCV
- Tương thích ngược: nếu còn trường đơn `template_path` ở nơi khác, runtime sẽ lấy template đầu tiên trong `templates[]` làm mặc định khi cần.
- Ví dụ rút gọn:
	{
		"name": "Coc go~",
		"description": "Quái rừng mở đầu",
		"window_bounds": { "left": 100, "top": 100, "width": 1280, "height": 720 },
		"templates": [
			{
				"name": "goc-45",
				"path": "assets/images/monsters/coc-45.png",
				"threshold": 0.85,
				"region_strategy": "window"
			},
			{
				"name": "zoom-gan",
				"path": "assets/images/monsters/coc-zoom.png",
				"threshold": 0.9,
				"region_strategy": "custom",
				"region": [200, 150, 600, 300]
			}
		]
	}

3. **Rotation Logic in auto_hunt.py** (~160 lines)
   - `get_monster_rotation_targets(cfg)`:
     • Build rotation list from enabled monsters
     • Match templates using fuzzy matching (case-insensitive, special chars ignored)
     • Sort by priority if priority mode
     • Returns: `[{name, priority, templates[]}, ...]`
   
   - `locate_monster_target(monster_targets, window_bounds)`:
     • Try to find any monster from rotation list
     • Iterate through monsters in order (sequence) or priority (priority)
     • Return first match: (box, template_info, monster_name)
   
   - **Fuzzy Matching Algorithm**:
     ```python
     import re
     def clean(name):
         return re.sub(r'[^a-z0-9\s]', '', name.lower())
     
     # "Coc go~" → "coc go"
     # "Coc Go" → "coc go"
     # ✅ Match successful!
     ```
     • Handles: case differences, special chars (~, !, -, etc.)
     • Partial names: "coc" matches "Coc Go", "Coc Go 2-5"
   
   - **Rotation Modes**:
     • **Sequence**: Hunt monsters in order, cycle through list
       - Current index tracking: `current_monster_index`
       - On target lost: `index = (index + 1) % len(monsters)`
       - Persists rotation state to config
     
     • **Priority**: Always hunt highest priority (lowest number)
       - Sort monsters by priority: `sorted(monsters, key=lambda m: m['priority'])`
       - Try all monsters in priority order every cycle
       - Never switches unless target lost
   
   - **State Machine Updates**:
     • `lost_timeout_sec`: Keep attacking after visual lost (default: 0.5s)
     • `attack_min_duration_sec`: Minimum attack time before switch (default: 5.0s)
     • State transitions: search → attack (found) → search (lost after timeout)
     • Console logging: `[Match] Monster: Coc Go 2 [sequence]`, `[Lost] after 6.2s`, `[Rotation] Switching to: Coc Go (2/3)`

```python
def _create_tooltip(self, widget, text):
    """Create a simple tooltip for a widget."""
    def on_enter(event):
        tooltip = tk.Toplevel()
        tooltip.wm_overrideredirect(True)
        tooltip.wm_geometry(f"+{event.x_root+10}+{event.y_root+10}")
        label = tk.Label(tooltip, text=text, background="#ffffe0", 
                        relief='solid', borderwidth=1, padx=5, pady=3)
        label.pack()
        widget._tooltip = tooltip
    
    def on_leave(event):
        if hasattr(widget, '_tooltip'):
            widget._tooltip.destroy()
            delattr(widget, '_tooltip')
    
    widget.bind('<Enter>', on_enter)
    widget.bind('<Leave>', on_leave)
```

**Features:**
- Yellow background (#ffffe0) - standard tooltip color

- Auto-destroys on mouse leave
- Reusable for any widget

```python
    - Timing Calculator: Auto-calculate and apply timing recommendations
    """
    
    def __init__(self, parent, hunt_cfg, lang='vi', on_close_callback=None):
        """
        Args:
            parent: Main app window

            lang: Language ('en' or 'vi')
            on_close_callback: Function to call when window closes with changes
        """
        
    def _build_monster_tab(self, parent):
        """Monster Library tab with list view and CRUD buttons."""
        
    def _build_skill_tab(self, parent):
        """Skill Library tab with list view and CRUD buttons."""
        
    def _build_timing_tab(self, parent):
        """Timing Calculator tab with auto-calculation and apply."""
        
    def _calculate_recommended_timing(self):
        """Calculate timing based on current skill configuration."""
        
    def _apply_timing_to_config(self):
        """Apply calculated timing to hunt_config Advanced Settings."""
        
    def _on_window_close(self):
        """Handle window close, trigger callback if changes made."""
```

## Bug Fix Summary: Timing Recommendation Unhashable Dict Error

**Date**: October 18, 2025 (Late Evening)
**Severity**: Critical (blocks timing calculation)
**Status**: ✅ Fixed

### Problem
```
Error: cannot use 'dict' as a dict key (unhashable type: 'dict')
```

User could not use timing recommendation feature. Error occurred when clicking "Tính thời gian" button.

### Root Cause
**Data Structure Mismatch**:
- Code assumed `skill_slots` is array of STRINGS: `["Dark Explosion", "Bone Javelin", ...]`
- Actual format in hunt_config.json is array of DICTS:
  ```json
  "skill_slots": [
    {
      "name": "Dark Explosion",
      "key": "1",
      "type": "attack",
      "cooldown": 1.9,
      "cast_time": 1.7,
      "image": "assets/images/skills/..."
    }
  ]
  ```

### Solution
Changed code to extract skill name from dict objects:

```python
# ❌ OLD CODE (assumes strings)
for skill_name in configured_skills:
    if skill_name in skill_dict:  # TypeError: dict is not hashable!

# ✅ NEW CODE (handles dict objects)
for skill_slot in configured_skills:
    if isinstance(skill_slot, dict):
        skill_name = skill_slot.get('name', '')
        skill_type = skill_slot.get('type', 'attack').lower()
    else:
        # Fallback for string format
        skill_name = skill_slot
```

=============================================================================
INTEGRATION WITH SKILL_RUNTIME.PY
=============================================================================

Workflow:
---------
1. User configures buff in GUI
   - Sets duration_sec and pre_refresh_sec

2. GUI saves to skills.json
   - Validation ensures correct values

3. skill_runtime.py loads skills.json
   - Parses duration_sec and pre_refresh_sec

4. SkillRuntime manages buff timing
   - needs_refresh() checks: (duration - elapsed) <= pre_refresh
   - get_buff_to_cast() returns buff key when ready

5. auto_hunt.py casts buff automatically
   - No manual intervention needed
   - Seamless buff uptime during hunting

Example Code Flow:
------------------
# GUI: User saves buff with duration=60, pre_refresh=5
skill = {
    "name": "Regeneration",
    "type": "buff",
    "duration_sec": 60.0,
    "pre_refresh_sec": 5.0,
    ...
}
save_to_skills_json(skill)

# skill_runtime.py: Load and manage
runtime = SkillRuntime(skills_data)
buff_info = SkillInfo(
    name="Regeneration",
    duration_sec=60.0,
    pre_refresh_sec=5.0,
    last_cast_time=0.0,
    ...
)

# auto_hunt.py: Auto-cast loop
now = time.time()
buff_key = runtime.get_buff_to_cast(now)
if buff_key:  # Returns key when needs_refresh() is True
    tap(buff_key)
    runtime.mark_cast(buff_key, now)

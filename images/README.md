# Icon Library for Library Manager

## Icon Set: Material Design Icons (Free)

This directory contains icons for the Library Manager UI.

### Icons Used:
1. **add.png** - Add/Create new item (Green #4CAF50)
2. **edit.png** - Edit existing item (Blue #2196F3)
3. **delete.png** - Delete item (Red #F44336)
4. **save.png** - Save changes (Green #4CAF50)
5. **cancel.png** - Cancel action (Gray #757575)
6. **folder.png** - Browse files (Gray #757575)
7. **capture.png** - Screen capture (Purple #9C27B0)
8. **search.png** - Search icon (Gray #757575)

### Icon Specifications:
- Format: PNG with transparency
- Size: 24x24 pixels (for buttons)
- Colors: Material Design palette
- Style: Flat, modern, consistent

### Fallback:
If icons are not available, the app will use Unicode emoji characters as fallback.
